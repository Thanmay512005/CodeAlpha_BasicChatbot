# Basic Chatbot

A small rule-based chatbot made with Python for the CodeAlpha Python Programming task.

## What it does

The chatbot reads a message from the user and gives a predefined reply.

- Type `hello` or `hi` to get a greeting.
- Type `how are you` to get a reply.
- Type `bye` to end the conversation.
- For other messages, it displays a simple fallback reply.

## Requirements

- Python 3
- No extra libraries are needed.

## How to run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

The program uses a function, if-elif conditions, a while loop, and console input/output.
